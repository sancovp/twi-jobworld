# B6 Outreach Engine — What We Need to Purchase / Provision

To take the outreach engine live for B6. Cost ranges are ballparks — confirm current
pricing at signup. **Start the domains ASAP** — they need ~2–4 weeks of warmup before
any real send, so they're the long pole on the calendar.

---

## REQUIRED — needed to send at all

| # | Item | What it's for | Rough cost | Notes |
|---|---|---|---|---|
| 1 | **Instantly** (subscription) | Cold-email sending + **domain warmup + deliverability** — the part that gets us into inboxes | **~$37–97/mo** | Tier by sending volume. This is the deliverability backbone. |
| 1a | **Cold sending domains** ×2–3 | The "from" domains — separate from **b6studios.com** (never send from the main domain) | ~$10–15/yr each | Easiest: buy through Instantly's **done-for-you (DFY)** option so they handle DNS + warmup. |
| 1b | **Mailboxes** (2–3 per domain) | The actual sending inboxes (~30–50 emails/day each) | Instantly DFY add-on, **or** Google Workspace ~$6–7/mailbox/mo | More mailboxes = more daily volume. |
| 2 | **Tracked-link host** (domain + small hosting) | Serves the personalized teaser links + click/view tracking | Domain ~$12/yr + hosting ~$5–10/mo | Can reuse existing infra if available. |
| 3 | **LLM / model credits** | The engine's copy writing + lead qualification | usage-based, **~$10–30/mo** at pilot volume | MiniMax or Anthropic (Claude) API. |

## Rough monthly total (pilot scale)

- **Lean floor:** Instantly basic + free Census + minimal host/LLM ≈ **~$60–80/mo**
- **Realistic** (Instantly higher tier + mailboxes + video): **~$120–180/mo**
- Domains are a small once-a-year cost; fal.ai video is usage-based on top.

## Once purchased, what to send back to us

So we can flip the engine on:
1. **Instantly API key** + the **campaign ID** (we'll tell you the one campaign to set up)
2. **fal.ai API key** (only if doing video)
3. The **host domain** for tracked links
4. Confirmation the **sending domains are bought and warming has started** in Instantly
